--------------------------------------------------------

routes/
Each file is a group of endpoints.

Examples:

profile.py → /profile

projects.py → /projects

skills.py → /skills

status.py → /status

This keeps your API clean and modular.

--------------------------------------------------------

models/
Pydantic models that define your JSON structure.

Example:

class Project(BaseModel):
    name: str
    description: str
    url: str
    tags: list[str]
